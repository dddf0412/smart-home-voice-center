# 智能家居语音环境中心

基于 **51 单片机（STC89C52RC）** 与 **ESP8266** 的智能家居系统，完整覆盖物联网「感知层—网络层—应用层」三层架构，实现环境监测、语音交互、自动环境调节、异常报警与远程控制的一体化。

## 文档

| 文档 | 说明 |
|------|------|
| [设计文档](IoT智能家居语音环境中心_设计文档.md) | 系统架构、硬件清单与引脚、核心功能、通信协议、关键技术点 |
| [接线与注意事项](接线与注意事项.md) | NodeMCU/ESP8266 引脚分布与启动注意事项 |

## 目录结构

```
.
├── main.py                                  电脑端主程序（网页控制台 + 语音桥接 + 数据存档）
├── templates/
│   └── index.html                           网页前端（ECharts 实时曲线 + 控制按钮）
├── esp8266_voice_center/
│   └── esp8266_voice_center.ino             ESP8266 固件（MQTT 上云 + 语音）
├── ly51s/
│   └── main.c                               51 单片机固件（感知 + 执行）
├── IoT智能家居语音环境中心_设计文档.md        设计文档
└── 接线与注意事项.md                         接线说明
```

## 运行环境

| 部分 | 环境 |
|------|------|
| 51 固件 | Keil C51（STC89C52RC @ 12MHz） |
| ESP8266 固件 | Arduino IDE（NodeMCU V3，需安装 PubSubClient 库） |
| 电脑端 | Python 3 + Flask + paho-mqtt + websocket-client（或直接运行打包后的 exe） |

## 隐私说明

本仓库为**脱敏版本**，涉及隐私的密钥已用占位符替换，运行前请替换为真实值：

| 文件 | 占位符 |
|------|--------|
| `main.py` | `你的巴法云私钥`、`你的讯飞AppID` / `你的讯飞APIKey` / `你的讯飞APISecret` |
| `esp8266_voice_center.ino` | `你的WiFi名` / `你的WiFi密码`、`你的巴法云私钥`、`PC_IP(192, 168, 1, 100)` |

> 注：打包成品 `smart_home.exe` 因包含编译进二进制的密钥，未包含在本仓库中；如需演示 exe，请用填入真实密钥后的源码重新打包。
